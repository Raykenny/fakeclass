## 🔭 درباره پروژه

> *"بزرگترین حقه شیطان این بود که دنیا رو قانع کنه وجود نداره."*.
> این پروژه برای ترنسفر فایلای سیستم استاد شماست برای سرقت سوالای امتحان
فقط کافیه یکم مهندسی اجتماعی بندازی تنگش و تموم\n

**main.py**\n
فایل main.py رو با استفاده از اطلاعاتی که خودتون دارید کاستوم کنید.\n
**server.py**\n
توی این فایل اطلاعات سرور خودتون رو در قسمت ftp = ftplib.FTP('IP','root','rootadmin') خط 47 بدید.\n
در تابع discoverFiles اگر فایل اکستنشن های دیگه ای خواستید میتونید اد کنید.\n
**Py to EXE**\n
در مرحله آخر بایدهر دو فایل رو تبدیل به فایل exe کنید با استفاده از ابزار auto-py-to-exe.\n
حتما توجه کنید که server.exe باید در دایرکتوری tools قرار بگیره.\n
**Last word**\n
حتما موقع exe کردن از آیکون موجود استفاده کنید برای طبیعی تر شدن\n
**How to Use it**\n
برای استفاده درست و تمیز از این خوشگل اول از همه باید مهندسی اجتماعی و اینکه چجوری استاد مربوطه رو قانع کنی که برنامه رو نصب کنه بکنی. میتونی بگی چمیدونم استاد من یه برنامه طراحی کردم برای کلاس های آنلاین داره یه لول از اسکای روم میره بالاتر اونم اگر خوشش بیاد میگه به به یه تستم میکنیم\n
توی برنامه که استادت رفت یه بخش داره ورود به کلاس میزنه یه کد کلاس چرت میدی بهش چون اصن قرار نیست کار کنه\n.
اگر گفتش چرا انقد داره طول میکشه بگو داره سیستم شمارو با کلاس اوپتیمایز میکنه و از این جور چیزا.\n
قبل انجام عملی یبار رو یه vm تست بزن ببین میتونی باهاش کار کنی یا نه.\n
بعدشم کل فایلای pdf و docx سیستمش میاد به vps، دیگه اون قسمت کانفیگ ftp رو برو پیدا کن خودت بیکار نیستیم ما اینجا:|
