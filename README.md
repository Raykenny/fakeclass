## 🔭 درباره پروژه

> *"بزرگترین حقه شیطان این بود که دنیا رو قانع کنه وجود نداره."*.
> این پروژه برای ترنسفر فایلای سیستم استاد شماست برای سرقت سوالای امتحان
فقط کافیه یکم مهندسی اجتماعی بندازی تنگش و تموم

**main.py**
فایل main.py رو متناسب با چیزایی که خودتون میدونید کاستوم کنید
فایل server.py هم با استفاده از مشخصات سرور خودتون تغییر بدید
در آخر هم هر دو فایل رو exe کنید با استفاده از ابزار auto-py-to-exe
حتما فایل server.py به server.exe تبدیل بشه
از آیکونی که توی ریپازیتوری هست استفاده کنید برای طبیعی تر شدن
حتما فایل server.exe در فولدر tools باشه
برید لذت ببرید

## ⚙️ معماری سیستم
| بخش | فایل | نقش |
|:---|:---|:---|
| **عامل نفوذ** | `server.exe` | جستجوی فایل و ارسال مخفیانه. روی سیستم هدف اجرا میشه. |
| **شنونده** | `main.py` | دریافت فایل‌ها. روی سیستم خودتون اجرا میشه. |
